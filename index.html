What I do

Web Design

Web design refers to the design of websites that are displayed on the internet. It usually refers to the user experience of website development.

UI UX Design

UI is a place where interactions between humans and machines occur. UX is the experience that a person has they interact with a product.

Responsive Design

Responsive web design is creating web pages that look good on all devices. A responsive web design will adjust for different screen sizes and viewports.

Graphics Design

Graphic design is disciplinary branch of design and of the fine arts. They focus on the logic of display elements in interactive designs to optimize the user experience.

App Design

App design combines the user interface and user experience. While UI focus itself to the overall style of the app general look and feel. UX focus on the functional and usability.

Logo Design

A logo is a symbol or design used to identify a company or organization. A logo generally involves symbols, stylized text or both.
